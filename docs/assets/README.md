# Documentation Assets

This directory holds binary/vector assets referenced by the documentation
in `docs/README.md` (and potentially other docs):

- `benchmark-donut.svg` — donut chart of request-quality benchmarks.
- `architecture-diagram.svg` — high-level request-flow architecture diagram.

These are visual companions only; they are not documentation pages and do
not carry an ADR/guide format. Edit the SVGs directly when the underlying
numbers or architecture change.
