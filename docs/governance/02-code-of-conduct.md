# 02. Code of Conduct

- **Status:** Active
- **Date:** 2026-08-23
- **Deciders:** @Githab-capibara
- **Related:** [docs/README.md](../README.md)

We want FreeQwenApi to be a welcoming project for everyone.

## Purpose

Standards for respectful collaboration and enforcement procedures.

## Our standards

- Be respectful and assume good intent.
- Critique ideas, not people.
- Keep discussions on-topic and constructive.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks.
- Publishing others' private information without consent.
- Deliberately disruptive or trolling behaviour.

## Enforcement

Report problems to the maintainer via
[Telegram](https://t.me/forgetmeai). Maintainers may remove contributions or
block contributors who violate this code.

This Code of Conduct is adapted from the spirit of the Contributor Covenant.
